## Comment ça marche

Chaque session de 1h30 suit le même gabarit : 10 min de rappel actif, 65 min sur un objectif unique défini à l'avance, 15 min de journal. Le code des exercices et projets est écrit à la main — l'IA sert de tuteur, pas de générateur. La roadmap est révisée à chaque fin de phase, et le plan détaillé de la phase suivante est généré à ce moment-là.
